# Setup

#### Setup

1. **Install VS Code Extensions**: Open VS Code, navigate to the Extensions section on the left tab, and install the Python, Pylance, and Jupyter extensions.
2. **Clone the Repository**: Open the VS Code Terminal and clone the Tradeboard repository with the command:

`git clone` [`https://github.com/wesoftcorp/tradeboard-docs`](https://github.com/wesoftcorp/tradeboard-docs)
