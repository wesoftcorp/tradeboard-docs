# Orders API

Order endpoints place, modify, cancel, inspect, and close orders or positions through the active broker session or analyzer mode.

| Endpoint | Purpose |
|---|---|
| [Place order](placeorder.md) | Place one regular order |
| [Place smart order](placesmartorder.md) | Place an order relative to current position size |
| [Options order](optionsorder.md) | Resolve and trade one option contract |
| [Options multi-order](optionsmultiorder.md) | Resolve and trade multiple option legs |
| [Basket order](basketorder.md) | Submit multiple regular orders |
| [Split order](splitorder.md) | Split a large quantity into smaller orders |
| [Modify order](modifyorder.md) | Modify an existing regular order |
| [Cancel order](cancelorder.md) | Cancel one regular order |
| [Cancel all orders](cancelallorder.md) | Cancel eligible open orders |
| [Close position](closeposition.md) | Close eligible open positions |
| [Place GTT](placegttorder.md) | Create a GTT trigger |
| [Modify GTT](modifygttorder.md) | Modify a GTT trigger |
| [Cancel GTT](cancelgttorder.md) | Cancel a GTT trigger |
| [GTT order book](gttorderbook.md) | List GTT triggers |
| [Order status](orderstatus.md) | Read one order's status |
| [Open position](openposition.md) | Read one symbol's open position |
