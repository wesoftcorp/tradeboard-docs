# Accounts API

Account, analyzer, preference, and health endpoints share the Tradeboard v1 base URL and use the application API key.

| Endpoint | Purpose |
|---|---|
| [Ping](ping.md) | Verify API-key authentication |
| [Funds](funds.md) | Read account funds and limits |
| [Margin](margin.md) | Calculate order margin requirements |
| [Order book](orderbook.md) | Read the current order book |
| [Trade book](tradebook.md) | Read executed trades |
| [Position book](positionbook.md) | Read open and closed positions |
| [Holdings](holdings.md) | Read delivery holdings |
| [Analyzer status](analyzer-status.md) | Read live or analyzer mode |
| [Analyzer toggle](analyzer-toggle.md) | Switch live or analyzer mode |
| [P&L by symbol](pnl-symbols.md) | Read sandbox P&L grouped by symbol |
| [Chart preferences](chart-preferences.md) | Read or update TradingView chart preferences |
