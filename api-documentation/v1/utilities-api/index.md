# Utilities API

Calendar and messaging resources provide market schedules and opt-in alert delivery.

| Endpoint | Purpose |
|---|---|
| [Holidays](holidays.md) | Read exchange holidays |
| [Timings](timings.md) | Read the market schedule for a date |
| [Telegram](telegram.md) | Configure and operate Telegram delivery |
| [WhatsApp](whatsapp.md) | Send a WhatsApp notification |
