# API Collections

The Tradeboard API Collections are a comprehensive set of tools designed to streamline your journey into algorithmic trading. Hosted on [GitHub](https://github.com/wesoftcorp/tradeboard-docs/tree/main/collections), these collections offer an intuitive and ready-to-use interface to interact with Tradeboard’s powerful capabilities, making it easier for developers, traders, and enthusiasts to integrate and automate trading strategies.
